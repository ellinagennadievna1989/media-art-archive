# API «Архив медиаарта»

Учебное API на FastAPI с каталогом из 17 выбранных проектов Эллины Геннадьевны. Описания основаны на страницах сайта художницы; для неуточнённых сведений оставлены пустые поля, а не выдуманные данные. Обложки проектов извлечены из предоставленного портфолио PDF и сохранены локально в `static/images/`; для первой работы также включена галерея из четырёх предоставленных фотографий.

---

## Возможности

- Просмотр каталога из 17 проектов медиаарта.
- Отдельные страницы проектов с описаниями и изображениями.
- Поиск проектов по тегам.
- Локальное хранение изображений — для отображения обложек не требуется подключение к сайту-портфолио.
- Проверка состояния и версии приложения.
- Автоматические тесты и CI через GitHub Actions.

## Маршруты

| Метод | Маршрут | Описание |
|---|---|---|
| `GET` | `/` | Главная страница |
| `GET` | `/health` | Проверка состояния приложения |
| `GET` | `/version` | Имя и версия приложения |
| `GET` | `/projects` | Каталог проектов |
| `GET` | `/projects/{project_id}` | Данные проекта по ID |
| `GET` | `/projects/search?tag=нейросети` | Поиск проектов по тегу |
| `GET` | `/projects/{project_id}/page` | HTML-страница проекта |
| `GET` | `/docs` | Интерактивная документация Swagger |

## Установка (Windows PowerShell)

### 1. Создание виртуального окружения

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если PowerShell блокирует активацию окружения, можно использовать Python напрямую.

### 2. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
```

Если окружение не активировано, выполни:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

## Запуск

```powershell
uvicorn app_final:app
```

Открой в браузере:

- Главная страница: http://127.0.0.1:8000/
- Документация API: http://127.0.0.1:8000/docs
- Проверка состояния: http://127.0.0.1:8000/health
- Версия приложения: http://127.0.0.1:8000/version

Для обычного запуска не добавляй `--reload`.

## Тесты

Запусти автоматические тесты:

```powershell

```

## Настройки

Приложение поддерживает переменные окружения:

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `APP_NAME` | Название приложения | `Архив медиаарта` |
| `APP_VERSION` | Версия приложения | `1.0.0` |
| `LOG_LEVEL` | Уровень логирования | `INFO` |

Пример настроек находится в `.env.example`. Переменные можно задать в текущем сеансе PowerShell:

```powershell
$env:APP_NAME = "Архив медиаарта"
$env:APP_VERSION = "2.0.0"
$env:LOG_LEVEL = "INFO"
```

Файл `.env.example` служит образцом: само по себе его наличие не загружает переменные в окружение. Не добавляй настоящий `.env` или секреты в Git.

## Логирование и диагностика

Приложение записывает в логи запуск и остановку, HTTP-запросы и результаты поиска по тегам.

Если приложение не запускается:
1. Проверь установку зависимостей.
2. Убедись, что порт `8000` свободен.
3. Открой `/health` и `/version`.
4. Проверь сообщения в консоли, где запущен Uvicorn.
5. Выполни тесты командой `python -m pytest -v`.
